How to cite

If you use data or figures produced with this application, please cite both the application and the computation library behind it.

This application

ICTS-Doñana ({% now "Y" %}). Restore4Life — Danube Wetlands HydroApp: hydroperiod analysis of Danube basin wetlands. Estación Biológica de Doñana (EBD-CSIC). {{ request.scheme }}://{{ request.get_host }}. Accessed {% now "Y-m-d" %}.

The computation library

García Díaz, D. ndvi2gif: seasonal vegetation and hydroperiod analysis on Google Earth Engine. https://github.com/Digdgeo/Ndvi2Gif

Underlying data

Results derive from Copernicus Sentinel-2, USGS/NASA Landsat or NASA MODIS imagery, and — for the topographic wetness index — from MERIT Hydro and NASADEM. Each carries its own attribution requirements, which apply in addition to the above.

Licence

Commercial use of the data and any derived products is permitted, but their distribution must carry the same licence as the original data, and the source must always be cited.
